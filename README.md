# Customer Churn Analysis - Task 2

## Project Overview
Analyze customer data to identify patterns behind 
subscription cancellations and suggest improvements 
for retention.

## Analysis Performed
1. Calculated overall churn rate
2. Churn breakdown by subscription plan
3. Compared churned vs active customers
4. Identified high risk customers
5. Provided retention suggestions

## Key Findings
- Basic plan customers churn the most
- High support calls indicate frustration
- Inactive 30+ days customers are at high risk
- New customers need better onboarding
